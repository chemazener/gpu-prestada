    Qué hace este programa

    Convierte este ordenador en una segunda tarjeta gráfica para la inteligencia artificial de LoMasTrend. Cuando el servidor tiene trabajo de IA, puede enviárselo a este equipo para que lo resuelva su tarjeta NVIDIA.

    No te quita la tarjeta: si la estás usando tú (un juego, edición de vídeo…), deja de prestarla solo y vuelve cuando queda libre. También puedes pausarlo con el botón de arriba.

    Es privado: si tienes Tailscale, solo acepta conexiones de esa red privada; si no, es este programa el que se conecta a LoMasTrend por un canal cifrado con un código de alta. En ningún caso abre puertos a Internet.

    Puedes minimizar o cerrar esta ventana: el programa sigue funcionando en el icono junto al reloj. Para cerrarlo del todo, clic derecho en ese icono y «Salir».
